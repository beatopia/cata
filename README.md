# Cata

**Cata** is a 2D online multiplayer roguelike prototype built in Unity. I originally developed the project using Unity Version Control before moving it to GitHub for long-term storage and presentation.

Original pitch video: https://drive.google.com/file/d/1wYFG7Ay9ZiN2t1Xi3dWU27kHNXxShQEM/view?usp=sharing

This project was created as part of the Da Vinci CS Pathway game studio competition. Each honors student first built and pitched a vertical slice, then presented it to the CS pathway class. Students could apply to join different game studios, and Cata received the most applications. I founded and led the team through the full studio timeline, using Jira for sprint planning and Cursor to speed up development and iteration.

Over a 10-week timeline, our 6-person team built a playable multiplayer prototype in Unity with C# and Mirror. I led project planning, coordinated development tasks, managed version control, and helped implement client-server networking, including a test server hosted on AWS EC2.

Cata earned **1st Place - Game of the Year (2025)** among all Da Vinci CS Pathway game studios.
